# نسخه 1.5.10 — داشبورد مدیریتی و تنظیمات یکپارچه کاوه‌نگار

## بازطراحی صفحه اصلی
- نوار خوش‌آمدگویی روشن و مینیمال با دکمه‌های «ایجاد لیست جدید»، «گزارش پیامک‌های ارسالی» و «تنظیمات پیامک».
- چهار کارت آمار از داده‌های واقعی نماهای ذخیره‌شده: کل لیست‌ها، فرم‌های مرتبط یکتا، لیست‌های دارای پترن پیامک، لیست‌های دارای محدودیت کاربری.
- جدول خواناتر، جست‌وجوی بلادرنگ در عنوان/فرم/شناسه، فیلتر «همه/دارای پیامک/دسترسی محدود»، کپی کد کوتاه با یک کلیک، عملیات ویرایش و حذف با تأیید.
- حالت خالی اختصاصی وقتی هنوز لیستی وجود ندارد و حالت بدون نتیجه برای جست‌وجو.
- طراحی RTL واکنش‌گرا، CSS فقط در صفحه اصلی افزونه، بدون تغییر نمای سایت کاربران.

## تنظیمات مشترک کاوه‌نگار
- دیگر در «افزودن/ویرایش هر لیست» فیلد کلید API کاوه‌نگار وجود ندارد.
- کلید یک‌بار در داشبورد، زیر «تنظیمات افزونه → تنظیمات سرویس پیامک کاوه‌نگار» ذخیره می‌شود. همان کلید در همه ارسال‌های کاربر، مدیر و تست‌های SMS استفاده می‌شود.
- کلید سراسری در وردپرس با `autoload=false` ذخیره می‌شود، هرگز در HTML/JS پنل برگردانده نمی‌شود؛ برای جایگزینی، کلید جدید وارد و ذخیره می‌شود. خالی‌گذاشتن ورودی کلید قبلی را حفظ می‌کند. حذف فقط با انتخاب گزینه صریح حذف انجام می‌شود.
- مهاجرت: اگر بین رکوردهای نسخه قبلی یک کلید یکتا وجود داشته باشد خودکار به تنظیم سراسری منتقل می‌شود. اگر چند کلید متفاوت وجود داشته باشد، انتخاب خودکار انجام نمی‌شود و مدیر باید کلید صحیح را مشخص کند. ستون قدیمی برای سازگاری و امکان بازگشت نسخه پاک نمی‌شود اما کد جدید از آن برای ارسال استفاده نمی‌کند.
- محدودیت دسترسی مدیریت تنظیمات `manage_options` است.

## مشاهده سوابق ارسالی کاوه‌نگار
- دکمه داشبورد گزارش ارسالی را در همان صفحه باز می‌کند. ارتباط مستقیماً از PHP وردپرس به کاوه‌نگار برقرار می‌شود و کلید هرگز در مرورگر قرار نمی‌گیرد.
- **۱۰۰ پیامک اخیر:** `GET /v1/{apikey}/sms/latestoutbox.json?pagesize=100`
- **گزارش بازه:** `GET /v1/{apikey}/sms/selectoutbox.json?startdate=UNIX&enddate=UNIX`
- امکان انتخاب بازه تا ۳۱ روز (تاریخ در فرم **میلادی**)، جدول با شناسه، زمان، فرستنده، گیرنده، متن پیام و وضعیت به‌همراه صفحه‌بندی سمت کاربر، بدون ذخیره پیامک‌ها در دیتابیس وردپرس.
- گزارش حاوی پیامک‌های حساب کاوه‌نگار است و لزوماً محدود به همین افزونه نیست. میزان پوشش پیامک‌های Lookup و مدت آرشیو تابع گزارش‌دهی خود سرویس است.
- تنها مدیران با `manage_options` قادر به مشاهده هستند؛ AJAX دارای nonce مستقل، محدودیت اندازه پاسخ و URL ثابت HTTPS بدون دنبال‌کردن redirect است.
- هیچ پیامکی در فرایند مشاهده گزارش ارسال نمی‌شود.

## آزمون و انتشار
- نسخه افزونه: `1.5.10` (نیازمند انتشار GitHub Release با همین تگ).
- بدون تغییر ساختار جداول یا حذف تنظیمات نماهای فعلی.
- پس از انتشار، نسخه را ابتدا در استیجینگ نصب و تست کنید:
  1. بررسی انتقال خودکار کلید از نماهای قبلی و امکان ویرایش/حذف سراسری.
  2. ارسال یک پیامک آزمایشی با کلید سراسری.
  3. بازکردن گزارش اخیر و بازه زمانی با API واقعی.
  4. تست جست‌وجو، فیلترها، کپی کد کوتاه و عملیات حذف/ویرایش.
  5. بررسی دسترسی‌نداشتن کاربران بدون مجوز به کلید و گزارش.
- اجرای تست API واقعی، اعتبار سوابق و PHP lint روی هاست از این محیط ممکن نبود؛ پیش از نصب در سایت اصلی بررسی شود.
