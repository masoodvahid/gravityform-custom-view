# نسخه ۱.۷.۰ — بازطراحی ویرایش لیست نتایج و شماره همراه جایگزین

## تغییرات ظاهری و مدیریتی

- عنوان منوی اصلی افزونه: **مدیریت نمایش فرم**. دسترسی از قبل با قابلیت وردپرس `manage_options` به مدیران سایت محدود بوده و اکنون عنوان جدید حفظ‌کننده اسلاگ قدیمی `gf_custom_view` است.
- عنوان صفحه ویرایش: **ویرایش لیست نتایج**؛ عنوان فیلد: **عنوان لیست نمایشی**.
- **اتصال به فرم گرویتی فرم** و **عنوان لیست نمایشی** در یک ردیف؛ ترتیب راست‌به‌چپ از فرم به عنوان.
- فیلدهای «نام» و «نام خانوادگی» برای نام‌گذاری PDF در یک ردیف دو‌ستونه.
- عنوان بخش انتخاب فیلدهای جدول: **فیلدهای لیست نمایشی**.
- بخش «دسترسی و شماره‌های پیامک» قبل از «تنظیمات نمایش پاسخ‌ها» قرار گرفت. سه ستون راست‌به‌چپ: (۱) شناسه کاربران مجاز، (۲) شماره‌های موبایل مدیران، (۳) فیلد موبایل کاربر و فیلد موبایل جایگزین زیر آن.
- فهرست کشویی فیلد موبایل و فیلد جایگزین از فیلدهای فرم انتخاب‌شده (شامل زیرفیلدهای ترکیبی Gravity Forms) ساخته می‌شوند و با تغییر فرم فوراً به‌روز می‌شوند.
- با واردکردن شناسه کاربران وردپرس، نام و نام خانوادگی متناظر (یا نام نمایشی پروفایل) به صورت چیپ زیر فیلد نمایش داده می‌شود؛ برای شناسه ناموجود، اخطار «کاربر یافت نشد» نمایش داده می‌شود. این AJAX فقط برای کاربران `manage_options` فعال است.
- CSS صفحه ویرایش با `table-layout:fixed`، `min-width:0` و گریدهای واکنش‌گرا از خروج فیلدها و لیست انتخاب‌شده از کادر خاکستری جلوگیری می‌کند. در صفحه‌های کوچک ستون‌ها به شکل مناسب کاهش می‌یابند.

## تغییر دیتابیس و ارسال پیامک
ستون `fallback_mobile_field_id varchar(20) NOT NULL DEFAULT ''` با `dbDelta` در مهاجرت `gfcv_db_version=1.7.0` به جداول موجود اضافه می‌شود، بدون حذف مقادیر قبلی.

- اگر فیلد موبایل اصلی پر باشد، همان شماره استفاده می‌شود.
- **فقط اگر فیلد اصلی خالی باشد**، مقدار فیلد موبایل جایگزین خوانده می‌شود.
- این رفتار در پیش‌نمایش پیامک کاربر، ارسال تکی و ارسال سریع گروهی یکسان اعمال می‌شود.
- اگر هر دو فیلد خالی یا نامعتبر باشند، SMS ارسال نمی‌شود؛ پیامک گروهی چنین رکوردی را به همراه دلیل حذف نمایش می‌دهد.

## انتشار و کنترل
نسخه هدر وردپرس و ثابت `GFCV_PLUGIN_VERSION` هر دو **۱.۷.۰** هستند. پس از ادغام تغییرات و گذشتن CI، از آخرین commit شاخه main یک Release تازه با تگ `v1.7.0` بسازید تا تگ به نسخه ناقص اشاره نکند.

در سایت آزمایشی بررسی کنید: صفحه ویرایش در عرض ۱۳۶۶ و موبایل، انتخاب فیلدهای فرم، ذخیره مجدد لیست قدیمی، نمایش نام شناسه‌های مجاز، PDF نام فایل، SMS با شماره اصلی، SMS با شماره جایگزین وقتی اصلی خالی است و انتخاب گیرندگان در SMS گروهی.

کد با بررسی ایستا/CI آزموده می‌شود؛ عملکرد روی وردپرس مشتری بدون اتصال به سایت تضمین یا تأیید نشده است.
