# نسخه ۱.۶.۳ — پنجره پاپ‌آپ گزارش پیامک‌های ارسالی

گزارش سابقاً با یک `<details>` میان کارت‌های آماری و جدول لیست‌ها باز می‌شد؛ اکنون با دکمه بالای داشبورد به یک `<dialog>` مستقل و ریسپانسیو منتقل شده است.

## ویژگی‌ها

- بازشدن پاپ‌آپ بزرگ وسط صفحه (حداکثر ۱۱۶۰ پیکسل عرض، با پس‌زمینه نیمه‌شفاف).
- فیلتر قبلی «۱۰۰ پیام اخیر» و «بازه تاریخ» بدون تغییر در API.
- نمایش وضعیت درخواست و خطاهای کاوه‌نگار، جدول قابل اسکرول افقی و صفحه‌بندی ۱۵ ردیفی قبلی.
- بسته‌شدن با دکمه «بستن»، کلید Escape یا کلیک خارج از محتوای پنجره.
- امکان تمرکز صفحه‌کلید روی پنجره و بازگشت فوکوس به دکمه فراخوان پس از بستن.
- بارگذاری مجدد گزارش هنگام بازشدن پاپ‌آپ؛ دکمه «نمایش گزارش» نیز بازخوانی دستی را فراهم می‌کند.
- حفظ دسترسی فقط برای مدیر کل، nonce درخواست Ajax و کلید API سراسری (بدون تغییر سمت PHP سرویس).
- چیدمان راست‌به‌چپ و واکنش‌گرا، با اسکرول داخلی برای جلوگیری از خروج پاپ‌آپ از صفحه.

## تست

کنترل‌های ساختاری در کد: تگ‌های `dialog`، شناسه یکتای تمام عناصر، موجودبودن فرم فیلتر و دکمه‌های صفحه‌بندی، مدیریت بستن و فوکوس، و نحو JavaScript بررسی شدند. تست عملی داخل پنل وردپرس در مرورگر هنوز انجام نشده است.
